# Requirement / Test Traceability

Scope: Milestone 1 and Milestone 2 requirements JE-001..012, IDX-001..004, DET-001..003 and DATA-001/002. Requirement text is in `docs/requirements.md`. Every test name below exists and is verifiable with `go test -list . ./...`. Tests are in `internal/<package>/<file>`.

Execution gate (TechSpec 9.6): every M2 requirement has automated tests; deferred or narrowed requirements are recorded explicitly in the "Gaps" section.

## Milestone gates

- M1: `internal/worker/integration_test.go` `TestMilestone1EndToEndEntryToReady` (save, worker with fake provider, ready; raw file, front matter, canonical row, FTS, chunks, entities, embeddings, provenance, occurrences).
- M2: `internal/server/lifecycle_test.go` `TestMilestone2EntryLifecycleEndToEnd`. Through the HTTP routes with a running worker: create, ready, edit x2, delete, list hides, list with `include_deleted` shows `Deleted`, restore, resync. After each step it asserts the raw file, front matter, database counts and that exactly one previous version exists (zero before the first edit).
- Supporting M2 sequence test: `internal/entries/reprocess_test.go` `TestRepeatedEditResyncDeleteRestoreKeepsOneCoherentSetAndOnePrevious`.

## Gaps and changed requirements (explicit)

1. JE-005 media restriction: complete for images only (see table); `<video>`/`<iframe>` embeds are not detected.
2. JE-011 default exclusion from search, recall and statistics: Deferred until those features exist.
3. Worker concurrency greater than 1 is untested: with `Concurrency > 1` an edit can requeue while an older run is still active. Only single-worker behaviour is covered (`TestStaleRunCannotFinishJobReclaimedAfterEdit`, `TestConcurrentEditsAndResyncsConvergeOnTheLatestText` use one worker). Partial for JE-010.
4. `GET /entries` silently ignores invalid `include_deleted` and `page` values (treated as false and page 1); behaviour is unspecified and untested. Minor for JE-009.
5. `GET /entries/{id}/edit` still renders the form for a deleted entry; only the submit returns 409 (`TestDeleteAndRestoreFromEntryPage`). Minor for JE-011.
6. IDX-003 full rebuild from files alone (empty database) has no test.
